## Project template

When you start a new project:

1. Create folder: `projects/<project-name>/`
2. Copy `../.gitignore` (or add to root `.gitignore`)
3. Add `README.md` using this structure:

```markdown
# <project-name>

> One-paragraph description.

## Status
🚧 In progress | ✅ Complete | 📋 Planned

## Why this project
- Reason 1
- Reason 2

## Roadmap
- [ ] Milestone 1
- [ ] Milestone 2
- [ ] Milestone 3

## Tech stack
| Layer | Tool |

## Directory layout

## References
```

4. Add row to projects table above
5. Add row to root README projects table
6. Commit: `docs: scaffold <project-name>`
